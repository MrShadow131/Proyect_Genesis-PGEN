# Proyecto Genesis
PGEN o Proyect Genesis es un proyecto personal donde busco documentar y compartir mis avances de estudio de todas las ramas que yo quiero estudiar, tales como electronica, programacion, mecanica, robotica, soporte IT, entre otros cuantos. En este proyecto busco compartir ese progreso con ustedes, los lectores, contribuidores, y demas.
El lema es:
“No nací en lo más alto, pero desarrollaré lo suficiente para alcanzarlo.
No tengo una herencia millonaria, pero heredé el hambre y la ambición de todos mis ancestros.
Proyecto GENESIS es más que un proyecto personal, más que una proyección mía: es el símbolo del ser que aspiro a convertirme, y ese camino lo comparto con ustedes.”
— Facundo Scocozza

En este repositorio busco compartir con todos ustedes mis progresos, guias que ire haciendo acerca de tecnologias o temas o habilidades especificas.
